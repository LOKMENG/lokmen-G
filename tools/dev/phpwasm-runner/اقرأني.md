# مشغّل php-wasm (أداة تطوير)

بيئات التطوير التي لا تحتوي ملف `php` تنفيذياً تشغّل سكربتات المنصة عبر php-wasm:

```bash
mkdir -p ~/.php-bin && cd ~/.php-bin
npm init -y && npm install php-wasm@0.2.0
cp tools/dev/phpwasm-runner/run.mjs .
node run.mjs --root /home/user/lokmen-G tests/lint.php
node run.mjs --root /home/user/lokmen-G tests/run.php
node run.mjs --root /home/user/lokmen-G tools/dev/smoke.php --all
```

- ينسخ المشروع إلى `/proj` داخل ذاكرة php-wasm، ويعيد نسخ ما يُكتب في `storage/{import,build,tmp}` إلى المشروع الحقيقي.
- الملف مستثنى من حزمة النشر (`tools/dev`).
