# استيراد بنك أسئلة قديم (ملف SQL جاهز)

هذا الدليل يشرح كيف تُدخل ملفاً فيه **آلاف الأسئلة** مكتوباً بصيغة SQL قديمة — مثل ملفات
«تجميعات الرخصة المهنية» المنتشرة — داخل منصة **LOKMEN** بطريقة آمنة:
بلا إدخال أعمى، وبلا تخمين إجابة، ومع تصحيح آلي للأخطاء المطبعية المؤكدة فقط.

---

## 1) لماذا لا ينفع نسخ الملف وتنفيذه كما هو؟

ملفك يكتب الأسئلة عادةً هكذا:

```sql
INSERT INTO tracks (name, slug, description, display_order) VALUES ('التربوي العام','general','…',1);
INSERT INTO questions (id, category, source, stem, option_a, option_b, option_c, option_d, correct_answer)
VALUES (1, 'تجميعات الرخصة المهنية - عام', 'اديوميتر', 'نص السؤال', 'أ', 'ب', 'ج', 'د', NULL);
```

وهذه الجملة **لا تعمل** على المنصة للأسباب التالية:

| المشكلة | التفصيل |
|---|---|
| **أعمدة غير موجودة** | المنصة لا تملك أعمدة `category / source / stem`. بنودها: `track_id`, `category_id`, `subcategory_id`, `source_id`, `question_text`, `question_type`, `content_hash`, `needs_review` … |
| **المسارات** | جدول `tracks` في المنصة يستخدم `code / name_ar / name_en / icon / color`، وليس `name / slug`. كما أن المسارين مضافان أصلاً في `database.sql`. |
| **إجابات ناقصة** | أغلب أسئلة «اديوميتر» في هذه الملفات بلا إجابة (`correct_answer = NULL`). إدخالها كما هي يعني أسئلة غير قابلة للتصحيح. |
| **تشويه النص** | النص المستخرج من PDF يعاني من: انقلاب الهمزة (`اإلدارة` بدل `الإدارة`)، حروف مفصولة (`م ن` بدل `من`)، تكرار الهاء (`سههتخدم`)، همزة مفصولة (`الاستقصا ء`). |
| **تكرار** | التجميعات تكرر السؤال نفسه أكثر من مرة، و`questions.content_hash` في المنصة **فريد (UNIQUE)**. |
| **المعرّفات** | المعرّفات 1…1087 في ملفك تتعارض مع الأسئلة الموجودة في قاعدة بياناتك. |

لذلك هذا المستورد **لا ينفّذ ملفك أبداً**؛ يقرؤه فقط، ثم يحوّله إلى صيغة المنصة.

---

## 2) قواعد صارمة (لا يمكن تجاوزها)

1. **لا تُخمَّن الإجابة أبداً.** أي سؤال بلا إجابة في الملف يبقى بلا إجابة ويُوسم
   `الإجابة الصحيحة غير موجودة`، ولا يُدخل إلى بنك الأسئلة قبل أن يضبطه المراجع يدوياً.
2. **لا يُخمَّن أصل الكلمة المشوّهة.** الإصلاح الآلي يقتصر على ما هو مؤكد لغوياً:
   ترتيب المحارف (`اإل` → `الإ`)، إلصاق حرفين منفصلين (`م ن` → `من`)، إلصاق «ء» و«ة» المفصولتين،
   تصحيح المسافات حول علامات الترقيم. أما `سههتخدم` فتُوسم ولا تُعدَّل.
3. **المراجعة البشرية شرط قبل الإدخال.** كل صف يذهب إلى `import_staging` أولاً.
4. **الأسئلة الموسومة بـ «يحتاج مراجعة» لا تظهر للطلاب.**
   محرك الاختبار يستخدم شرط `exam_ready` (مفعّل + له إجابة + `needs_review = 0`)،
   فلا يمكن لسؤال ناقص أن يدخل اختباراً بالخطأ.
5. **حقوق المحتوى مسؤولية المالك.** يُسجَّل لكل مصدر `license_note` يوضح أن الملف من تقديم المالك؛
   ولا تُنسب الأسئلة إلى جهة رسمية، ولا تُقدَّم المجالات بوصفها تصنيفاً معلناً من هيئة التقويم.

---

## 3) التشغيل

من مجلد المشروع، على السيرفر أو على حاسوبك (PHP 8.1 فأحدث):

```bash
php tools/import-legacy-bank.php --file=/path/to/legacy.sql --out=/path/to/output
```

خيارات مفيدة:

| الخيار | المعنى | الافتراضي |
|---|---|---|
| `--file=` | مسار ملف SQL القديم | (مطلوب) |
| `--out=` | مجلد الإخراج | (مطلوب) |
| `--batch=` | اسم الدُفعة كما سيظهر في لوحة التحكم | اسم الملف |
| `--track=2` | المسار عند الإدخال الفوري: `2` التربوي العام، `1` التخصصي | `2` |
| `--min-score=2` | الحد الأدنى لنقاط التصنيف الآلي | `2` |
| `--chunk=100` | عدد الصفوف في كل جملة `INSERT` (يتجاوز حد حجم الطلب في phpMyAdmin) | `100` |
| `--split=0` | تقسيم صفوف المراجعة على عدة ملفات | `0` (ملف واحد) |
| `--no-dedupe` | تعطيل كشف التكرار | معطّل |

مثال لملف كبير (1087 سؤالاً) على استضافة محدودة:

```bash
php tools/import-legacy-bank.php --file=./tamyee3at.sql --out=./import-out \
     --batch="تجميعات الرخصة 1447" --track=2 --chunk=80 --split=4
```

> الأداة **لا تفتح اتصالاً بقاعدة البيانات**؛ مخرجاتها ملفات فقط.

## 4) الملفات الناتجة

| الملف | ماذا يفعل | متى تنفّذه |
|---|---|---|
| `00_tracks_categories.sql` | يصحّح جملة `tracks` القديمة ويضمن وجود مسارَي المنصة (بلا تكرار) | أولاً |
| `10_sources.sql` | ينشئ مصدراً لكل قيمة في عمود `source` (اديوميتر / تحدي القدرات) بلا تكرار | ثانياً |
| `20_staging.sql` (أو `20_staging_partNN.sql`) | يدخل **كل** الأسئلة في **منطقة المراجعة** `import_staging` + ينشئ الدُفعة | ثالثاً |
| `30_questions_ready.sql` | إدخال مباشر للأسئلة المستوفية للشروط فقط (لها إجابة + نص سليم + غير مكررة) | اختياري |
| `40_review.csv` | قائمة المراجعة البشرية (بـ BOM ليفتح عربياً في Excel) | للمراجعة |
| `REPORT.md` | تقرير بالأرقام: كم أُصلح، كم بلا إجابة، كم مكرر، التصنيفات المقترحة | للقراءة |
| `summary.json` | نفس الأرقام بصيغة آلية | للأدوات |

### أي ملف تختار؟

* **تريد الأمان الكامل (موصى به):** نفّذ `00` ← `10` ← `20` فقط، ثم راجع من لوحة التحكم.
* **تريد نتائج فورية أيضاً:** نفّذ `00` ← `10` ← `30` (يدخل النظيف فوراً) ثم `20`
  (يدخل الباقي للمراجعة). الصفوف التي أُدخلت في `30` لن تتكرر لاحقاً بفضل `content_hash` الفريد.

---

## 5) خطوات ما بعد التنفيذ (لوحة التحكم)

1. نفّذ الملفات في phpMyAdmin (تبويب SQL) أو:
   ```bash
   mysql -u USER -p DBNAME < 20_staging.sql
   ```
2. لوحة التحكم ← **استيراد الأسئلة** ← افتح الدُفعة.
3. راجع الصفوف: صحّح النص إن لزم، ثم **اضبط الإجابة الصحيحة** (أ/ب/ج/د) — الصفوف بلا إجابة لن تُعتمد.
4. اعتمد الصحيح (زر «اعتماد المحدد» أو «اعتماد كل الصالح»).
5. في نموذج الإدخال اختر: المسار، المصدر، الصعوبة، واترك
   **«استخدام التصنيف المقترح لكل صف»** مُفعّلاً ليأخذ كل سؤال مجاله المقترح،
   ثم اضغط **إدخال**.
6. الصفوف التي تُركت بلا إجابة تُدخل بحالة «يحتاج مراجعة» ولا تظهر للطلاب حتى تُصحّح من
   **بنك الأسئلة ← تصفية «تحتاج مراجعة»**.

---

## 6) التصنيف الآلي

تُقترح المجالات التربوية التسعة الموجودة في `database.sql` (أرقام 22–30):
المناهج وطرق التدريس، القياس والتقويم، علم النفس التربوي، الإدارة المدرسية والقيادة،
أخلاقيات المهنة، تكنولوجيا التعليم، الفروق الفردية وصعوبات التعلم، الإدارة الصفية،
البحث التربوي وتطوير الأداء المهني.

* التصنيف يعتمد على كلمات مفتاحية مميّزة، ويحتاج **مؤشرين على الأقل** ليقبل النتيجة.
* ما لم يُصنَّف يُوسم `لم يُتعرَّف على المجال آلياً`، ويمكن توزيعه يدوياً لاحقاً.
* أسئلة «تحدي القدرات» تُصنَّف بالمحتوى نفسه؛ وما بدا منها رياضيات/لغة عامة
  يُوسم `سؤال قدرات/لغة عامة` ليقرر المالك إبقاءه أو استبعاده.
* هذه مجالات **مرنة للمنصة** وليست تصنيفاً رسمياً معلناً من هيئة تقويم التعليم والتدريب.

---

## 7) استكشاف الأخطاء

| الرسالة | السبب | الحل |
|---|---|---|
| `لم يُعثر على أي جملة INSERT INTO questions` | الملف ليس بالصيغة المتوقعة | افتح الملف وتأكد من وجود `INSERT INTO questions ... VALUES` |
| `MySQL server has gone away` | حجم الجملة أكبر من `max_allowed_packet` | أعد التوليد بـ `--chunk=40 --split=4` |
| `Duplicate entry ... content_hash` عند إدخال `30` | نُفّذ الملف مرتين | طبيعي — تجاهل، أو احذف الملف وأعده |
| نص ما زال مقلوباً بعد الاستيراد | تشويه من نوع لا يجوز تخمينه | صحّحه يدوياً من قائمة المراجعة أو CSV |

## 8) للمطوّر

* الصنف: `src/LegacyBankImporter.php` (دوال ثابتة، بلا اعتماد على قاعدة بيانات).
* الأداة: `tools/import-legacy-bank.php`.
* الاختبارات: `php tests/run.php --filter=استيراد` (مجموعة «استيراد بنك قديم» في `tests/run.php`).
* وسوم المراجعة كلها معرّفة في `LegacyBankImporter::ISSUES` بوصف عربي، ويظهر وصفها في
  عمود `issues` داخل `import_staging` وفي ملف CSV.

## 9) مخططات أخرى (مثل `question` / `choix` / `explication`)

إن كان ملفك يستخدم أسماء جداول وأعمدة مختلفة تماماً — مثل المخطط الشائع:

```sql
question(id_question, id_categorie, texte_question, niveau_difficulté, année_hijri)
choix(id_question, numero_choix, texte_choix, est_correct)
explication(id_question, explication)
```

فالأداة لا تعرف هذا المخطط تلقائياً، لكن المحوّل يوفّر دالة عامة لقراءة أي ملف SQL:

```php
$tables = App\LegacyBankImporter::parseSqlFile($sql);   // كل جمل INSERT مجمّعة باسم الجدول
$rows   = App\LegacyBankImporter::process($mappedRows); // بعد تحويلها إلى shape المنصة
```

خطوات التحويل اليدوي:
1. اقرأ الجداول بـ `parseSqlFile()`.
2. حوّل كل صف إلى الشكل المطلوب في `process()`:
   `['stem','option_a'..'option_d','correct_answer','source','category','explanation','difficulty','year']`.
3. اربط تصنيفاتك بمجالات المنصة عبر الرمز (`code`) لا الاسم، حتى لا تتأثر بتعديل الأسماء.
4. استخرج الإجابة من `est_correct` (TRUE → الحرف المطابق بعد تحويله إلى a/b/c/d).
5. استخدم `promoteSql()` لإدخال الأسئلة الكاملة و`stagingSql()` للناقصة.

مثال كامل منفَّذ تجده في `storage/import/` (تحويل بنك الحاسب: 78 سؤالاً، 16 كاملاً أُدخلت،
62 ناقصة أُرسلت للمراجعة، و3 أسئلة موسومة بتعارض بين الإجابة والشرح).

> تنبيه: جمل `CREATE TABLE` الخاصة بالمخطط القديم **لا تُنفَّذ** على منصتك؛
> منصتك تملك بنيتها، وتنفيذها كان سيُنشئ جداول زائدة بلا فائدة.
