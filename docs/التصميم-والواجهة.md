# دليل التصميم والواجهة (طبقة Celadon)

يشرح هذا الدليل طبقة التصميم المستخدمة في المنصة: من أين جاءت، وكيف تُعدَّل، وكيف نحافظ عليها سليمة بعد أي تعديل مستقبلي.

---

## 1) من أين جاء التصميم

اتجاه الواجهة مستوحى من قالب **Celadon** (templatemo.com/tm-633-celadon) بأسلوب **الكلايمورفيزم (Claymorphism)**:

- ألواح طينية ناعمة بزوايا دائرية كبيرة، مع لمعة زجاجية (gloss) وحدّ داخلي مضيء (lip).
- انخفاض داخلي (well) للحقول والأشرطة، وبروز خارجي (clay shadow) للبطاقات والأزرار.
- لون الجّاد الأخضر (celadon/jade) كلون أساسي على خلفية باستيل باردة.
- لمسة نحاسية مرجانية (coral) للأزرار الثانوية والتنبيهات.

**شرط استخدام القالب:** روابط النسبة في الأسفل (`Design by TemplateMo · Tooplate`) موجودة في قوالب الصفحات الثلاثة (`views/layouts/public.php` و `app.php` و `auth.php`) داخل العنصر `.cl-credit` — يجب **عدم حذفها** لأنها شرط الاستخدام المجاني.

الملفات المعنية:

| الملف | الوظيفة |
|---|---|
| `assets/css/celadon.css` | الطبقة الكاملة للتصميم (رموز، مكوّنات، إعادة تلوين Bootstrap، هيكل اللوحة، الوضع الليلي). |
| `assets/js/celadon.js` | تفاعلات القالب: ظهور عند التمرير، عدّادات، مسار البطاقات، الأكورديون، زر الصعود، نسخ الكود. لا يعتمد على أي مكتبة خارجية. |
| `assets/css/app.css` | الطبقة البنيوية الأصلية للمنصة (الشبكة، القائمة الجانبية، بعض المكوّنات). تبقى ولا تُحذف. |
| `views/layouts/{public,app,auth}.php` + `views/exams/take.php` | تحميل `celadon.css` **بعد** `app.css`، و`celadon.js` **بعد** `app.js`. |

ترتيب التحميل مهم: أي تعديل يقلب الترتيب يجعل الأنماط القديمة تتغلّب على الجديدة.

## 2) رموز التصميم (Design Tokens)

كل الألوان والظلال معرّفة كمتغيرات CSS في أعلى `celadon.css`، لذلك تغيير مظهر المنصة كاملاً يحتاج تعديل بضعة أسطر فقط:

```css
:root {
    --cl-canvas: #E8EDF7;   /* خلفية الصفحة */
    --cl-plate: #F3F6FD;    /* سطح اللوح الطيني */
    --cl-sunk: #DCE4F3;     /* الحقول الغائرة */
    --cl-ink: #232D3C;      /* النص الأساسي */
    --cl-jade: #7CCFB0;     /* اللون الأساسي (celadon) */
    --cl-jade-ink: #2A7A62; /* نص بلون الجّاد */
    --cl-coral: #E8735C;    /* اللون الثانوي */
    --cl-r: 28px;           /* نصف قطر كبير للبطاقات */
    --cl-r-sm: 18px;
    --cl-r-xs: 13px;
}
```

> الألوان المخصّصة من لوحة الإدارة (`settings`) تبقى هي المرجع للتشغيل (الاسم، الشعار، الأسعار)، أما رموز `--cl-*` فهي هوية بصرية ثابتة.

**تغيير اللون الأساسي إلى لون آخر:** عدّل `--cl-jade` و`--cl-jade-ink` ورموز اللمعان الثلاثة (`--cl-gloss-jade`، `--cl-gloss-jade-down`، `--cl-lift-jade`) بنفس العائلة اللونية، ثم راجع الصفحات. الطبقة تحتوي أيضاً على الوضع الليلي في `[data-bs-theme="dark"]` بنفس الأسماء — عدّله بالمقابل.

## 3) المكوّنات الجاهزة (اختصارات يمكن استخدامها في أي قالب)

```html
<div class="cl-plate cl-plate-pad">لوح طيني</div>
<button class="cl-btn cl-btn-solid">زر أساسي</button>
<button class="cl-btn cl-btn-ghost">زر شفاف</button>
<button class="cl-btn cl-btn-coral cl-btn-sm">زر صغير مرجاني</button>
<div class="cl-well">حقل غائر</div>
<span class="cl-chip">شريحة</span>
<span class="cl-pill">كبسولة</span>
<span class="cl-eyebrow">كلمة صغيرة فوق العنوان</span>
<span class="cl-disc">نقطة مرقّمة</span>
```

### صفوف ومسارات

- `cl-grid` شبكة بطاقات متجاوبة، و`cl-hairline` فاصل رفيع.
- `cl-rail` + `cl-rail-track` + `cl-rail-prev/next`: مسار بطاقات قابل للسحب (يُستخدم لشهادات المتدربين في الصفحة الرئيسية).
- `cl-band-plate` + `cl-stave`: أكورديون (الأسئلة الشائعة واللوحات المطوية).

### هيكل اللوحة الداخلية

القائمة الجانبية والشريط العلوي في `views/partials/` تُنسَّق عبر الأصناف القديمة (`pl-sidebar`، `pl-topbar`، `pl-sidebar-nav`، `pl-page-title`…) وقد أُعيد تجهيزها بالهوية في القسم 12 و14 من `celadon.css` — لذلك أي تعديل في القالب الجانبي ينعكس تلقائياً.

## 4) التفاعلات التي يوفّرها `assets/js/celadon.js`

| الميزة | كيف تُستَخدم |
|---|---|
| ظهور عند التمرير | أضف `rv` إلى العنصر، و`d1`…`d4` لتأخير متدرّج. |
| عدّاد رقمي | `<span data-count-to="1250" data-count-prefix="" data-count-suffix="+">1250</span>` |
| مسار قابل للسحب | `[data-rail]` يحتوي `[data-rail-track]` وأزرار `[data-rail-prev]` / `[data-rail-next]`. |
| أكورديون | `[data-slab-group] > [data-slab-item] > [data-slab-head]` (أول عنصر `open`). |
| نسخ نص | أي عنصر يحمل `data-cl-copy` ينسخ قيمته إلى الحافظة. |
| زر الصعود | عنصر `#clUp` (مضاف في القوالب). |
| شريط علوي ملتصق | الأصناف تُضاف تلقائياً عند التمرير (`.stuck`). |

القواعد المهمة:

1. **لا مكتبات خارجية**: كل شيء في ملف واحد بدون jQuery.
2. **الوضع الليلي**: يُدار بالجذر `data-bs-theme` مع حفظ الاختيار في `localStorage`.
3. **تقليل الحركة**: احترام `prefers-reduced-motion` (تُلغى كل الحركات والانتقالات).
4. **بلا جافاسكربت**: الروابط تضيف الصنف `cl-js` إلى `<html>` أول شيء في الصفحة، وعناصر `rv` لا تُخفى إلا عند وجوده — فإن تعطّلت الجافاسكربت بقي المحتوى ظاهراً بالكامل.

## 5) كيف تتحقّق أن التعديل لم يكسر التصميم

من جذر المشروع:

```bash
# 1) فحص سلامة طبقة التصميم: توازن الأقواس، تغطية الأصناف، وجود المتغيرات وربط القوالب
php tools/dev/check-design.php

# 2) فحص صياغة PHP + اختبارات المنصة (تشمل الآن اختبارات طبقة التصميم)
php tests/lint.php
php tests/run.php

# 3) توليد معاينة ثابتة للصفحات دون قاعدة بيانات
php tools/dev/render-preview.php --list
php tools/dev/render-preview.php --route=index.php --print > /tmp/preview/index.html
```

`check-design.php` يفشل (رمز خروج 1) إذا:

- كان في `celadon.css` قوس `{` أو `}` غير متوازن؛
- استخدم أي قالب صنف CSS غير معرّف (بعد تجاهل أصناف Bootstrap وأصناف الأيقونات الديناميكية)؛
- كان متغيّر `--cl-*` مستخدماً وغير معرّف؛
- كان أحد القوالب لا يربط `celadon.css`.

## 6) قواعد عند إضافة شاشة جديدة

1. لا تكتب أنماطاً داخلية (`style="..."`) إلا للاستثناءات الديناميكية الصغيرة (أبعاد رسم بياني مثلاً).
2. استعمل أصناف الهوية: اللوح `cl-plate`، الزر `cl-btn`، الحقل `cl-well`، الجداول `table` العادية (تُنسَّق تلقائياً في الوضعين).
3. لكل جدول بيانات مهم أضف `cl-tabular` لثبات عرض الأرقام.
4. لا تضف صنفاً جديداً في القالب قبل تعريفه في `celadon.css`، وإلا سيفشل فحص `check-design.php`.
5. كل نص جديد بالعربية، وكل عنصر تفاعلي له تسمية `aria-label` أو نص ظاهر.
