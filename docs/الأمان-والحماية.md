# الأمان والحماية — منصة الرخصة المهنية (النسخة الأولى + تحسينات الأمان)

هذا الملف يوثّق ما هو **مطبَّق فعلاً في الكود**، وكيف تتحقق منه، وما المطلوب منك على الخادم.
القاعدة التي بُني عليها العمل: **لا أمن بالتخمين** — كل حماية مذكورة هنا لها كود يمكن قراءته.

---

## ١) ما هو مطبَّق في الكود

### أ) الحقن (SQL Injection)
- كل الاستعلامات تُنفَّذ عبر **Prepared Statements** مع ربط القيم (`src/Database.php`).
- لا يوجد أي مكان يُدمج فيه مدخل المستخدم مباشرةً داخل نص SQL.
- الاستثناء الوحيد المقصود: أسماء الجداول/الأعمدة الثابتة في الكود (ليست من مدخلات المستخدم).

### ب) التزييف عبر المواقع (CSRF)
- كل طلب `POST` يمرّ عبر بوابة تحقق من الرمز في `config/bootstrap.php`.
- الرمز: ٢٥٦ بت عشوائي، مرتبط بالجلسة، وله عمر محدود (`security.csrf_ttl`).
- المعفيون صراحةً فقط: **ويبهوك تلجرام** و**بوابات الدفع** (لأنها لا تملك الرمز)، وكل منها
  يتحقق بصورة مستقلة (توقيع/كلمة سر).

### ج) كلمات المرور والدخول
| الحماية | التفصيل |
|---|---|
| التخزين | **Argon2id** إن كان متاحاً، وإلا **bcrypt** بكلفة 12 |
| السياسة | حد أدنى ١٠ أحرف (قابل للزيادة)، ويشترط حرفاً لاتينياً ورقماً |
| رفض الشائعة | قائمة كلمات مرور شائعة (مع تجريد الأرقام والرموز الزائدة) |
| رفض الاشتقاق | تُرفض كلمة المرور المشتقة من البريد أو الاسم أو رقم الجوال |
| رفض الأنماط | التكرار (`aaaaaa`) والتسلسل (`12345678`, `abcdefgh`) |
| منع إعادة الاستخدام | لا تُقبل كلمة المرور الجديدة إن طابقت الحالية |
| تحديد المعدل | ٥ محاولات دخول ثم حظر ١٥ دقيقة · ٥ حسابات/IP/ساعة · ٥ طلبات إعادة تعيين/ساعة |
| الرسائل الموحّدة | رسالة واحدة عند فشل الدخول أو نسيان كلمة المرور (لا كشف لحساب موجود) |
| استمرار «تذكّرني» | رمز عشوائي طويل، يُلغى عند تغيير كلمة المرور |

فحص قوة كلمة المرور متاح برمجياً عبر `App\Security::passwordScore()` (من ٠ إلى ١٠٠).

### د) الجلسات
- `session.use_strict_mode` و`use_only_cookies` مضبوطتان من الكود عند كل طلب.
- تجديد معرّف الجلسة عند الدخول (`session_regenerate_id(true)`).
- إنهاء الجلسة عند **الخمول** (`SESSION_IDLE_MINUTES`، افتراضي ١٢٠ دقيقة)
  أو عند تجاوز **العمر الأقصى** (`SESSION_MAX_MINUTES`، افتراضي ٧٢٠ دقيقة).
- بصمة متصفح اختيارية (`SESSION_FINGERPRINT`).
- كوكي الجلسة: `HttpOnly` + `SameSite=Lax`، و`Secure` عند تفعيل `SESSION_SECURE`.

### هـ) الرؤوس (HTTP Headers)
تُرسَل تلقائياً من `App\Security::sendSecurityHeaders()`:

```
X-Content-Type-Options: nosniff
X-Frame-Options: SAMEORIGIN
Referrer-Policy: strict-origin-when-cross-origin
Permissions-Policy: geolocation=(), microphone=(), camera=()
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Resource-Policy: same-origin
X-Permitted-Cross-Domain-Policies: none
X-DNS-Prefetch-Control: off
Content-Security-Policy: ... object-src 'none'; frame-ancestors 'self'
Strict-Transport-Security: max-age=... (عند HTTPS فقط)
```
مع `header_remove('Server')` لإخفاء توقيع الخادم.
يمكن تعطيلها كاملاً بـ `SECURITY_HEADERS=false` إن تعارضت مع طبقة خارجية.

### و) الملفات والرفع
- `uploads/.htaccess` يمنع تنفيذ أي سكربت داخل مجلد الرفع.
- فلترة الامتدادات ونوع MIME، ورفض `php/phtml/phar/…`.
- `.htaccess` الجذري يحجب: `.env`، `config/`، `src/`，`includes/`，`views/`，`storage/`，`tests/`，`tools/`，`docs/`，`database.sql`،
  ويمنع عرض محتويات المجلدات (`Options -Indexes`).
- لخوادم nginx: انسخ القواعد من `docs/nginx-security.example.conf`.

### ز) التعمية والأسرار
- `APP_KEY` (٦٤ حرفاً سداسياً) يشفّر مفاتيح بوابات الدفع بـ **AES-256-GCM**.
- لا يُخزَّن أي مفتاح دفع في قاعدة البيانات بنصّه الصريح.
- ملف `.env` خارج المتصفح، وصلاحيته المقترحة `640`.

### ح) التدقيق والسجلات
- جدول `audit_logs` لكل عملية إدارية حساسة.
- `App\Logger::security()` يسجّل الأحداث الأمنية (تجاوز المعدل، دخول فاشل، جلسة منتهية،
  محاولة وصول للوحة الإدارة من IP غير مصرّح).
- السجلات في `storage/logs/` — **انقلها خارج المجلد العام إن أمكن**.

### ط) تحديد المعدل (Rate Limiting) يعمل حتى بلا قاعدة بيانات
`App\Security::exceededLimit()` يقرأ من قاعدة البيانات **ومن ملف** ويأخذ **الأكبر**
(`max($dbCount, $fileCount)`) — أي أن الحماية **تفشل مغلقة**: إن تعطّلت قاعدة البيانات
يستمر العدّ عبر الملفات في `storage/cache/ratelimit/` بدل أن يُسمح بالدخول.

## ٢) جديد هذه النسخة مقارنةً بالنسخة الأولى

| # | التحسين | أين |
|---|---|---|
| ١ | سياسة كلمة مرور قوية (طول + تنوع + قائمة سوداء + اشتقاق + أنماط) | `src/Security.php` |
| ٢ | مؤشر قوة كلمة المرور ٠–١٠٠ | `Security::passwordScore()` |
| ٣ | تحديد معدل **مقاوم لانقطاع قاعدة البيانات** (ملف + قاعدة) | `Security::exceededLimit()` |

| ٥ | منع إعادة استخدام كلمة المرور الحالية | `Auth::changePassword()` |
| ٦ | إنهاء الجلسة بالخمول والعمر الأقصى | `config/bootstrap.php` |
| ٧ | تحويل إجباري إلى HTTPS اختياري (`FORCE_HTTPS`) | `config/bootstrap.php` |
| ٨ | حصر لوحة `/admin` بعناوين IP (`ADMIN_IP_ALLOWLIST`) | `config/bootstrap.php` |
| ٩ | رؤوس حماية إضافية (COOP/CORP/Permitted-Cross-Domain/DNS-Prefetch) وإخفاء `Server` | `Security::sendSecurityHeaders()` |

## ٣) كيف تتحقق بنفسك

### من سطر الأوامر
```bash
php tools/security-audit.php                      # تقرير عربي
php tools/security-audit.php --json               # تقرير آلي
php tools/security-audit.php --url=https://موقعك   # + فحص المسارات الحساسة عبر HTTP
php tools/security-audit.php --fix-perms          # إصلاح صلاحية .env
```
رمز الخروج: `1` إن وُجد بند «خطر».

### من المتصفح (للاستضافة المشتركة)
لوحة التحكم ← **فحص الحماية** — نفس الفحوصات بالضبط، مع زرّ إصلاح صلاحية `.env`
ونموذج فحص HTTP.

### اختبارات المشروع
```bash
php tests/run.php          # ٦٥ اختباراً تشمل سياسة كلمة المرور وتحديد المعدل
php tests/lint.php         # فحص الصياغة لكل الملفات
```

## ٤) إعدادات الأمان في `.env`

```dotenv
FORCE_HTTPS=false            # true بعد تركيب الشهادة
SESSION_SECURE=false         # true بعد تركيب الشهادة
SESSION_IDLE_MINUTES=120     # إنهاء الجلسة بعد ساعتين من عدم النشاط
SESSION_MAX_MINUTES=720      # أقصى عمر للجلسة ١٢ ساعة
PASSWORD_MIN_LENGTH=10
RESET_MAX_PER_HOUR=5
REGISTER_MAX_PER_IP=5
ADMIN_IP_ALLOWLIST=          # مثال: 203.0.113.5,198.51.100.7
SECURITY_HEADERS=true
AUDIT_SECURITY_EVENTS=true
CRON_TOKEN=                  # رمز طويل لتشغيل tools/cron.php عبر الويب
```

## ٥) قائمة تحقّق قبل التشغيل الفعلي

- [ ] `APP_DEBUG=false` و`APP_ENV=production`
- [ ] `APP_KEY` بطول ٦٤ حرفاً سداسياً
- [ ] **حذف `install.php`** (أو إعادة تسميته)
- [ ] شهادة SSL مركّبة، ثم `SESSION_SECURE=true` و`FORCE_HTTPS=true`
- [ ] تغيير كلمة مرور المدير (وأي كلمة مرور افتراضية)
- [ ] صلاحية `.env` = `640`
- [ ] `database.sql` و`composer.json` خارج المجلد العام (أو محجوبة)
- [ ] مجلد `storage/` قابل للكتابة فقط (لا تنفيذ)
- [ ] `uploads/.htaccess` موجود
- [ ] مهمة Cron مضبوطة (`tools/cron.php --task=all` أو الرابط بالرمز)
- [ ] نسخة احتياطية تُحفظ **خارج** نفس الخادم (الاستضافة المجانية لا توفّر استعادة مجانية)

## ٦) حدود يجب معرفتها (بصدق)

- المنصة **لا تحمي من** ضعف كلمة مرور المدير نفسه، ولا من خادم غير محدَّث.
- الحماية من الهجمات الموزّعة (DDoS) مسؤولية الخادم/الشبكة، لا الكود.
- تحديد المعدل يعتمد على عنوان IP؛ ويمكن الالتفاف عليه عبر شبكات VPN — لذلك هو طبقة
  إبطاء وليس منعاً قاطعاً.
- مراجعة أسئلة بنك الأسئلة عملية بشرية: الكود يمنع **الإدخال الأعمى**، ولا يضمن صحة
  الإجابة إلا بعد تأكيد المراجع.
