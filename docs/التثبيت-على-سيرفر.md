# دليل النشر على سيرفر خاص

دليل عملي لرفع «منصة الرخصة المهنية» على استضافة مشتركة (cPanel) أو سيرفر خاص (VPS).
اتبع القسم المناسب لبيئتك، ثم أكمل «ما بعد التثبيت» في نهاية الملف.

---

## 1) المتطلبات

| المتطلب | التفصيل |
|---|---|
| PHP | 8.1 أو أحدث (يُفضّل 8.2 أو 8.3) |
| إضافات PHP | `pdo_mysql`، `mbstring`، `json`، `openssl`، `fileinfo` (مطلوبة) — `zlib` (لاستخراج أسئلة PDF) — `curl` (لتلجرام وبوابات الدفع) — `zip` (لبناء حزمة النشر) |
| قاعدة البيانات | MySQL 5.7+ أو MariaDB 10.4+ بترميز `utf8mb4` |
| الويب | Apache مع `mod_rewrite` و `AllowOverride All`، أو Nginx مع قاعدة إعادة كتابة (مرفقة أدناه) |
| شهادة SSL | مطلوبة عملياً (الكوكيز الآمنة + ويبهوك تلجرام + بوابات الدفع) |

> المنصة تعمل كاملة بالدفع اليدوي (تحويل بنكي / STC Pay / نقداً) بدون أي مفاتيح دفع،
> ويمكنك لاحقاً تفعيل Moyasar أو MyFatoorah من لوحة الإدارة.

## 2) الطريقة (أ): استضافة مشتركة — cPanel / DirectAdmin

### أ-1) بناء حزمة النشر

على جهازك (أو بعد رفع الملفات):

```bash
php tools/build-package.php
# الناتج: storage/build/lokmen-license-YYYYMMDD-HHMMSS.zip
```

لنسخة كاملة (تضم الاختبارات وأدوات الفحص لتعمل فحوصات ما بعد النشر):

```bash
php tools/build-package.php --with-tests --out=/path/lokmen-license.zip
```

نسخة جاهزة للرفع (`lokmen-license-v1.1.0-*.zip`) متوفرة بجانب مجلد المشروع في مساحة العمل،
تبنيها الأداة أعلاه، ولا تُحفظ الحزم داخل المستودع (مجلد `dist/` مستثنى من Git).

للتحقق من سلامة الملفات قبل الرفع (بلا إنترنت ولا مكتبات خارجية):

```bash
php tests/lint.php            # صياغة كل ملفات PHP
php tools/dev/validate-sql.php # database.sql: الجمل، الجداول، العروض، البيانات الأولية
php tests/run.php             # اختبارات المنطق على قاعدة بيانات وهمية
php tools/dev/smoke.php --all # فحص دخاني: تُشغَّل كل صفحة وتُفحص مخرجاتها
```

إن لم تتوفر إضافة `zip`، ارفع مجلد المشروع كاملاً مع **استثناء**:
`.git` — `.env` — `node_modules` — `storage/logs/*` — `storage/build` — `uploads/*` (ابقِ المجلدات الفارغة).

### أ-2) الرفع

1. من cPanel افتح **File Manager** (أو استخدم FTP/FileZilla).
2. ارفع ملف ZIP إلى `public_html` أو إلى المجلد الفرعي المطلوب (مثل `public_html/license`).
3. فك الضغط، ثم انقل **محتويات** المجلد `lokmen-license-platform` إلى المجلد الهدف
   (أو اتركه واجعل الرابط `https://example.com/lokmen-license-platform`).
4. تأكد من أن المجلدات موجودة: `storage`, `storage/logs`, `storage/cache`, `uploads`, `uploads/payments`, `uploads/receipts`, `uploads/questions`.

### أ-3) إنشاء قاعدة البيانات

1. من cPanel → **MySQL Databases**:
   - أنشئ قاعدة بيانات (مثال: `myuser_license`).
   - أنشئ مستخدماً وكلمة مرور قوية.
   - امنح المستخدم كل الصلاحيات على القاعدة (**All Privileges**).
2. دوّن: اسم القاعدة، اسم المستخدم، كلمة المرور، والخادم (عادةً `localhost`).

### أ-4) اختيار إصدار PHP والإضافات

من cPanel → **MultiPHP Manager** / **Select PHP Version`:
- اختر PHP 8.1 أو أحدث للمجلد.
- من **PHP Extensions** فعّل: `pdo_mysql`, `mbstring`, `openssl`, `fileinfo`, `zlib`, `curl`.

### أ-5) التشغيل

افتح في المتصفح:

```
https://your-domain.com/install.php
```

ثم:

1. **فحص المتطلبات** — يجب أن تكون كل العناصر «مطلوبة» متوفرة. إن ظهر عنصر مطلوب ناقص، اعالجه من لوحة الاستضافة.
2. **قاعدة البيانات** — أدخل البيانات التي دوّنتها. إن مُنح المستخدم صلاحية الإنشاء يمكنك ترك خيار «أنشئ قاعدة البيانات تلقائياً» مفعّلاً.
3. **الموقع والمدير** — ادخل اسم المنصة، الرابط النهائي (مثال `https://example.com`)، سعر الاشتراك (100 افتراضياً)، وبيانات حساب المدير.
   - اترك «حذف حسابات العرض التجريبية» مفعّلاً على السيرفر الحقيقي.
   - أدخل توكن البوت إن كنت جاهزاً لتفعيل تلجرام (يمكن إضافته لاحقاً).
4. **التنفيذ** — يكتب المعالج `.env`، ويستورد `database.sql`، وينشئ حساب المدير، ويقفل نفسه.

### أ-6) الصلاحيات

من File Manager → Permissions:

| المسار | الصلاحية |
|---|---|
| `storage` و `storage/logs` و `storage/cache` | `755` (أو `775` إن احتاج السيرفر) |
| `uploads` ومجلداته الفرعية | `755` |
| `.env` | `600` أو `640` |
| بقية الملفات | `644` والمجلدات `755` |

> إن ظهر خطأ «تعذّر الكتابة» فالمطلوب غالباً `775` أو `777` مؤقتاً على `storage` فقط، ثم أعده إلى `755`.

### أ-7) احذف المعالج

بعد نجاح التثبيت **احذف `install.php`** من File Manager.
(المعالج مقفول تلقائياً بملف `storage/installed.lock`، لكن الحذف أفضل.)

## 3) الطريقة (ب): سيرفر خاص (VPS) — Ubuntu + Nginx

### ب-1) الحزم

```bash
sudo apt update
sudo apt install -y nginx mysql-server \
  php8.2-fpm php8.2-mysql php8.2-mbstring php8.2-curl php8.2-zip \
  php8.2-openssl php8.2-fileinfo php8.2-gd php8.2-intl unzip
```

### ب-2) قاعدة البيانات

```bash
sudo mysql
```
```sql
CREATE DATABASE license_platform DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'license_user'@'localhost' IDENTIFIED BY 'كلمة-مرور-قوية';
GRANT ALL PRIVILEGES ON license_platform.* TO 'license_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

### ب-3) رفع الملفات

```bash
sudo mkdir -p /var/www/lokmen
cd /var/www/lokmen
# ارفع الحزمة ثم:
unzip lokmen-license-*.zip && mv lokmen-license-platform/* . && rmdir lokmen-license-platform
sudo chown -R www-data:www-data /var/www/lokmen
sudo find . -type d -exec chmod 755 {} \;
sudo find . -type f -exec chmod 644 {} \;
sudo chmod -R 775 storage uploads
```

### ب-4) Nginx

أنشئ `/etc/nginx/sites-available/lokmen`:

```nginx
server {
    listen 80;
    server_name example.com www.example.com;
    root /var/www/lokmen;
    index index.php;
    client_max_body_size 12M;

    # منع الوصول للملفات والمجلدات الحساسة
    location ~* ^/(\.env|database\.sql|composer\.(json|lock))$ { deny all; }
    location ~* ^/(config|src|views|includes|storage|tests|tools|docs)/ { deny all; }
    location ~* /\.(?!well-known) { deny all; }

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    # روابط جميلة بدون .php (بديل .htaccess)
    location ~ ^/([A-Za-z0-9_/-]+)$ {
        try_files $uri $uri/ /$1.php /index.php?$query_string;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
        fastcgi_read_timeout 120;
    }

    location ~* \.(css|js|woff2?|ttf|png|jpg|jpeg|gif|svg|webp|ico)$ {
        expires 7d;
        access_log off;
        try_files $uri =404;
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/lokmen /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

> **Apache بدلاً من Nginx:** وجّه `DocumentRoot` إلى `/var/www/lokmen`، واسمح بالتحقق من `.htaccess`:
> ```apache
> <Directory /var/www/lokmen>
>     AllowOverride All
>     Require all granted
> </Directory>
> ```

### ب-5) HTTPS

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d example.com -d www.example.com
```

### ب-6) التثبيت

**الطريقة الأسرع — المعالج الرسومي:** افتح `https://example.com/install.php` واتبع الحقول.

**أو من سطر الأوامر (مناسب للنشر التلقائي):**

```bash
cd /var/www/lokmen
sudo -u www-data php tools/install-cli.php \
  --db-host=localhost --db-name=license_platform --db-user=license_user --db-pass='كلمة-المرور' \
  --url=https://example.com --name="منصة الرخصة المهنية" \
  --admin-name="اسم المدير" --admin-email=admin@example.com \
  --admin-phone=0551234567 --admin-pass='كلمة-مرور-قوية1' \
  --price=100 --days=365 --yes
```

المعاملات المتاحة: `--db-host --db-port --db-name --db-user --db-pass --url --name --admin-name --admin-email --admin-phone --admin-pass --price --days --create-db --reset --yes`

بعد النجاح احذف المعالج:

```bash
sudo rm /var/www/lokmen/install.php
```

## 4) ملف الإعدادات `.env`

يُكتب تلقائياً من المعالج. للمراجعة أو التعديل اليدوي:

| المتغير | الوصف | القيمة المطلوبة على السيرفر |
|---|---|---|
| `APP_NAME` | اسم المنصة | نص عربي |
| `APP_ENV` | البيئة | `production` |
| `APP_DEBUG` | إظهار تفاصيل الأخطاء | **`false`** على السيرفر |
| `APP_URL` | الرابط النهائي | `https://example.com` (بدون `/` في النهاية) |
| `APP_KEY` | مفتاح التشفير | يولّده المعالج — **لا تغيّره بعد التشغيل** |
| `APP_TIMEZONE` | المنطقة الزمنية | `Asia/Riyadh` |
| `DB_*` | بيانات قاعدة البيانات | من خطوة إنشاء القاعدة |
| `SESSION_SECURE` | كوكيز الجلسة عبر HTTPS فقط | `true` |
| `SUBSCRIPTION_PRICE` / `SUBSCRIPTION_DAYS` | سعر ومدة الاشتراك | `100` / `365` (قابل للتعديل من لوحة الإدارة) |
| `TELEGRAM_BOT_TOKEN` | توكن البوت | من @BotFather (اختياري) |
| `TELEGRAM_BOT_USERNAME` | اسم مستخدم البوت | مثل `MyLicenseBot` |
| `TELEGRAM_WEBHOOK_SECRET` | سر الويبهوك | يولّده النظام عند تسجيل الويبهوك |
| `MOYASAR_*` / `MYFATOORAH_*` | بوابات الدفع | فارغة = الدفع اليدوي فقط |

> ملف `.env` محجوب عن الوصول المباشر عبر `.htaccess` وقاعدة Nginx، ومستثنى من Git.

## 5) بوت تلجرام

البوت **اختياري للطالب** (الربط طوعي)، ويمكن تشغيله بطريقتين:

### خيار 1: ويبهوك (يتطلب HTTPS عام)

من لوحة الإدارة → **تلجرام** → «تسجيل الويبهوك»، أو:

```bash
php telegram/set-webhook.php          # تسجيل
php telegram/set-webhook.php --info   # عرض الحالة
php telegram/set-webhook.php --delete # حذف الويبهوك
```

### خيار 2: Polling (بدون ويبهوك — مناسب للسيرفرات المقيدة)

```bash
php telegram/poll.php                 # حلقة مستمرة
php telegram/poll.php --minutes=60     # لمدة ساعة
```

> لا تُشغّل الويبهوك والـ Polling معاً في نفس الوقت.

أوامر الطالب داخل البوت: `/start` `/link` `/status` `/today` `/practice` `/stats` `/subscribe` `/support` `/unlink` `/privacy` `/cancel`.

## 6) المهام المجدولة (Cron)

أمر واحد يغطي كل الصيانة الدورية (إنهاء الاشتراكات، تنبيهات القرب من الانتهاء، إغلاق الاختبارات المتأخرة، تنظيف الملفات المؤقتة):

```bash
cd /var/www/lokmen && php tools/cron.php
```

cPanel → **Cron Jobs**:

```
*/5 * * * *
/path/to/php /home/USER/public_html/license/tools/cron.php >/dev/null 2>&1
```

سيرفر خاص (crontab لـ `www-data`):

```bash
sudo -u www-data crontab -e
# */5 * * * * cd /var/www/lokmen && php tools/cron.php >/dev/null 2>&1
```

خيارات: `--task=subscriptions|notify|exams|cleanup` و `--quiet`.
يتحقق من آخر تشغيل عبر إعداد `cron_last_run_at` في جدول `settings`.

## 7) بوابات الدفع

- **افتراضياً:** الدفع اليدوي (تحويل بنكي / STC Pay / نقداً في المركز). يرفع الطالب إثبات التحويل، ويعتمده المدير من «المدفوعات».
- **بيانات الحساب البنكي** تظهر للطالب من إعدادات لوحة الإدارة → الإعدادات → الاشتراك.
- **Moyasar (مدى / Apple Pay / فيزا):** فعّل `MOYASAR_ENABLED=true` وأضف المفاتيح، ثم اجعل رابط الإشعار (Webhook):
  `https://example.com/api/payments/callback.php?gateway=moyasar`
- **MyFatoorah:** فعّل `MYFATOORAH_ENABLED=true` وأضف `MYFATOORAH_API_KEY` ورابط الإشعار:
  `https://example.com/api/payments/callback.php?gateway=myfatoorah`

> النظام يتحقق من صحة الإشعار ومن مطابقة المبلغ (±1 ريال) قبل تفعيل الاشتراك.

## 8) النسخ الاحتياطي والاستعادة

نسخة كاملة (قاعدة بيانات + ملفات مرفوعة):

```bash
# نسخ قاعدة البيانات
mysqldump -u license_user -p license_platform | gzip > backup-db-$(date +%F).sql.gz

# نسخ الملفات المرفوعة والإعدادات
tar -czf backup-files-$(date +%F).tar.gz .env uploads/ storage/logs/

# استعادة
gunzip < backup-db-2026-01-01.sql.gz | mysql -u license_user -p license_platform
tar -xzf backup-files-2026-01-01.tar.gz
```

الجدولان الأهم للنسخ: `questions` و `users`، ثم `subscriptions` و `payments` و `exam_attempts`.

## 9) التحديث لاحقاً

1. **خُذ نسخة احتياطية** أولاً.
2. احتفظ بملف `.env` ومجلدي `uploads/` و `storage/` كما هي.
3. استبدل ملفات الكود بالنسخة الجديدة (عدا `.env`).
4. نفّذ `php tests/lint.php` للتأكد من سلامة الصياغة، ثم افتح أي صفحة للتأكد من عدم وجود أخطاء.
5. إن أصدرت النسخة الجديدة تغييرات في قاعدة البيانات، سيُرفق ملف SQL للتحديث — استورده من phpMyAdmin.
6. لتصفير التخزين المؤقت: احذف محتويات `storage/cache` (عدا `.gitkeep`).

## 10) قائمة فحص أمنية قبل الإطلاق

- [ ] `APP_DEBUG=false` و `APP_ENV=production`.
- [ ] حُذف `install.php` من السيرفر.
- [ ] `.env` بصلاحيات 600/640 ولا يمكن الوصول إليه من المتصفح (افتح `https://example.com/.env` يجب أن يعطي 403/404).
- [ ] `https://example.com/config/config.php` و `https://example.com/storage/logs/` لا يفتحان.
- [ ] كلمات مرور المدير قوية، وحسابات العرض التجريبية محذوفة.
- [ ] مهمة Cron مفعّلة وتعمل (تحقق من `cron_last_run_at`).
- [ ] نسخة احتياطية مجدولة (يومياً على الأقل).
- [ ] تم توثيق حق استخدام كل ملف PDF أُدخل إلى بنك الأسئلة (حقل المصدر).
- [ ] HTTPS مفعّل والشهادة صالحة، و`SESSION_SECURE=true`.

## 11) حل المشكلات الشائعة

| المشكلة | السبب المحتمل | الحل |
|---|---|---|
| خطأ 500 فور رفع الملفات | `php_value` في `.htaccess` مع PHP-FPM | الملف يغلّفها بـ `<IfModule mod_php*>`؛ إن بقي الخطأ فراجع `.user.ini` أو استخدم Nginx |
| «لم يتم العثور على ملف الإعدادات» مع تحويل إلى install.php | لا يوجد `.env` | أكمل المعالج أو نفّذ `cp .env.example .env` وعدّل القيم |
| «تعذّر الاتصال بقاعدة البيانات» | بيانات خاطئة أو المستخدم بلا صلاحيات | تحقق من `DB_*` ومن منح كل الصلاحيات للمستخدم |
| الصفحات الداخلية 404 بدون `.php` | `mod_rewrite`/`AllowOverride` مغلق أو قاعدة Nginx ناقصة | فعّل `AllowOverride All`، أو اجعل `APP_PRETTY_URLS=false` في `.env` |
| الروابط تعمل بمسار خاطئ داخل مجلد فرعي | `APP_URL` غير صحيح | اضبط `APP_URL=https://example.com/subfolder` |
| لا يمكن رفع ملف PDF كبير | حدود الرفع | ارفع `upload_max_filesize` و `post_max_size` من لوحة الاستضافة أو `.user.ini` |
| الويبهوك يُرفض | لا HTTPS عام أو سر خاطئ | استخدم `telegram/poll.php`، أو أعد تسجيل الويبهوك من اللوحة |
| الاستيراد من PDF لا يعمل | `zlib` مغلقة أو الملف ممسوح ضوئياً (صور) | فعّل `zlib`، أو استخرج النص بـ OCR ثم ارفعه TXT/CSV |
| الاشتراكات لا تنتهي تلقائياً | Cron غير مفعّل | أضف مهمة `tools/cron.php` |
| صفحات تظهر قديمة بعد التحديث | تخزين مؤقت | احذف `storage/cache/*` وحدّث بمفتاح `Ctrl+F5` |

للتشخيص: `storage/logs/` يحتوي سجلات التطبيق، و`storage/logs/cron.log` لمهام الصيانة.

## 12) اختبارات سريعة بعد النشر

```bash
php tests/lint.php             # فحص صياغة كل ملفات PHP
php tools/dev/validate-sql.php # فحص database.sql (الجمل/الجداول/العروض/البيانات الأولية)
php tests/run.php              # اختبارات منطق المنصة (بدون لمس MySQL)
php tools/dev/smoke.php --all  # فحص دخاني لكل الصفحات (تأكد من عمل الواجهات قبل الإطلاق)
php tests/run.php --real-db    # اختبارات على قاعدة البيانات الفعلية (بحذر: تُنشئ بيانات تجريبية)
```

`tools/dev/smoke.php` يُشغّل كل صفحة بصلاحية مناسبة (زائر/طالب/مدير) على قاعدة بيانات وهمية،
ويفشل إن ظهر أي خطأ PHP أو تحذير في مخرجات الصفحة — مفيد جداً بعد أي تعديل على القوالب.

ملاحظة: اختبار «تشفير مفاتيح بوابات الدفع» يُتخطّى تلقائياً قبل ضبط `APP_KEY` في `.env`،
لأنه يحتاج مفتاح التشفير الفعلي — بعد إتمام التثبيت أعِد تشغيل الاختبارات لتراه ناجحاً.

ثم من المتصفح: الصفحة الرئيسية → تسجيل حساب طالب → اختبار تجريبي → لوحة الإدارة → سؤال تجريبي →
الاشتراك → اعتماد الدفع → الإحصاءات.
