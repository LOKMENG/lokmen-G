# البنكان المرفقان: كيف أُدخلا في قاعدة البيانات

المنصة تتبع سياسة ثابتة: **لا إدخال أعمى ولا تخمين للإجابات.**
لذلك عُومل البنكان بمسارين مختلفين حسب طبيعة كل ملف:

| البنك | الحالة | المسار |
|---|---|---|
| بنك الحاسب الآلي (٥١ سؤالاً) | نص سليم، إجابة وشـرح لكل سؤال | **إدراج مباشر** في `questions` بعد مراجعة كل سؤال |
| البنك التربوي (١٠٨٧ سؤالاً) | نص مستخرج آلياً (OCR) وفيه كلمات مقطوعة، والإجابات من المصدر (٦٣٥ منها بصيغة «مقترحة») | **منطقة مراجعة** `import_staging` → اعتماد يدوي سؤالاً بسؤال |

## الملفات الناتجة

```
storage/import/attached-banks/
├── 01-sources.sql                        مصادر المحتوى (إقرار حقوق الاستخدام)
├── 02-computer-bank-51.sql               إدراج مباشر: ٥١ سؤالاً تخصصياً
├── 03-educational-bank-1087-review.sql   منطقة المراجعة: ١٠٧٥ صفاً
└── REPORT.md                             أرقام التوليد الفعلية
```

## طريقة الإدخال

```bash
mysql -u USER -p DBNAME < storage/import/attached-banks/01-sources.sql
mysql -u USER -p DBNAME < storage/import/attached-banks/02-computer-bank-51.sql
mysql -u USER -p DBNAME < storage/import/attached-banks/03-educational-bank-1087-review.sql
```

أو عبر phpMyAdmin: تبويب **استيراد** ← اختر الملف بالترتيب أعلاه.

ثم في لوحة التحكم: **استيراد من PDF / CSV ← مراجعة الدفعة (١٠٠١)** — صحّح النص،
أكّد الإجابة، ثم اعتمد. الأسئلة المعتمدة فقط هي ما يدخل بنك الأسئلة ويظهر للطلاب.

## لماذا لم يُدرج البنك التربوي مباشرة؟

1. **النص**: الاستخراج الآلي ترك حروفاً مفردة وكلمات مقطوعة (نحو ٥١٪ من الصفوف عليها
   علامة «يحتمل ضرر في النص»). أُصلح ما يمكن إصلاحه ميكانيكياً («ال» المشوّهة،
   الحروف المزدوجة، توحيد سطر الإجابة)، لكن تصحيح المعنى يحتاج مراجعاً بشرياً.
2. **الإجابة**: ٦٣٥ سؤالاً إجابتها بصيغة «الإجابة المقترحة» = غير مؤكدة، وتوزيع
   الحروف غير متوازن (نحو ٥٤٪ الخيار أ). إدخالها كما هي يعني نشر إجابات قد تكون خاطئة.
3. **السياسة**: ما لا يُتأكد منه يُرسل للمراجعة ولا يُخمَّن — وهذا أصل تصميم
   جدول `import_staging`.

## إعادة التوليد

عدّل الملف المصدر في `storage/import/raw/` ثم:

```bash
php tools/build-attached-banks.php                    # يستخدم النص المُصلَّح للتربوي
php tools/build-attached-banks.php --raw-educational  # يستخدم الملف الأصلي كما هو
```

الإدراج **آمن عند التكرار**: `INSERT IGNORE` في بنك الحاسب، و`ON DUPLICATE KEY`
للدفعة ١٠٠١ — أي إعادة تنفيذ لن تضاعف الأسئلة (بفضل مفتاح `content_hash` الفريد).

## تنبيه حقوقي وتنظيمي

- هذه الأسئلة من **ملفات يملك صاحب المنصة حق استخدامها**، ولم تُنسخ من أي مصدر محمي.
- تصنيفات المنصة (المجالات والمحاور) **تصنيفات مرنة من إعدادنا**، وليست تصنيفاً رسمياً
  معلناً من هيئة تقويم التعليم والتدريب، ويمكن تعديلها من لوحة التحكم.
