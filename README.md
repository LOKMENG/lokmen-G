# lokmen-G

## وثائق المرشد الطلابي — نموذج معايير التقويم والاعتماد المدرسي 2026

ثمانية ملفات Word منفصلة (DOCX)، كل ملف بعنوان في صفحة واحدة (A4)، بقالب احترافي عربي (RTL)،
مطوّرة من الإضاءات الثمانية للمؤشر: **«يلتزم المتعلمون بقواعد السلوك والانضباط المدرسي»**
— المجال: نواتج التعلم | المعيار: التطور الشخصي والصحي والاجتماعي.

كل صفحة تتضمن: الفكرة المحورية — إثراء أدوار المرشد الطلابي — خطوات التنفيذ — مؤشرات النجاح —
سيناريو تطبيقي — أدوات التقويم وفق النموذج (استبانة المعلم ☑ | المقابلات ☑ | تحليل الوثائق ☑).

### الملفات (في مجلد `docs/`)

**الوثيقة الموحدة (ملف واحد):** `00-الوثيقة-الموحدة-الإضاءات-الثمانية.docx` — غلاف وفهرس + الإضاءات الثمانية، كل إضاءة في صفحة مستقلة بعنوانها.

| # | الملف | عنوان الإضاءة |
|---|-------|----------------|
| 1 | `01-توحيد-الأداء-المؤسسي.docx` | توحيد الأداء في جميع مؤشرات معيار قيادة العملية التعليمية |
| 2 | `02-البرامج-التوعوية-للسلوك-والانضباط.docx` | تعزيز الوعي بالسلوك والانضباط عبر البرامج التوعوية المنظمة |
| 3 | `03-التضمين-في-الخطة-التشغيلية.docx` | تضمين الالتزام بقواعد السلوك والمواظبة في الخطة التشغيلية |
| 4 | `04-المتابعة-اليومية-للحضور-والسلوك.docx` | المتابعة اليومية للحضور والانصراف والسلوك ومعالجة الانحرافات |
| 5 | `05-برامج-التحفيز-والتكريم.docx` | تعزيز السلوك الإيجابي عبر برامج التحفيز والتكريم |
| 6 | `06-إجراءات-المعالجة-والجلسات-الإرشادية.docx` | إجراءات عادلة لمعالجة المخالفات وتفعيل الجلسات الإرشادية |
| 7 | `07-بيئة-مدرسة-منظمة-وآمنة.docx` | تهيئة بيئة مدرسية منظمة وآمنة تعزز الانضباط المدرسي |
| 8 | `08-المتابعة-والتقويم-وتطوير-الإجراءات.docx` | متابعة وتقويم الالتزام بقواعد السلوك وتطوير الإجراءات الوقائية |

### إعادة التوليد

```bash
python3 -m pip install --target .pytools --break-system-packages python-docx pillow
PYTHONPATH=.pytools python3 scripts/generate_onepagers.py
```

الخط: **Calibri Light**، الألوان: أخضر الهوية #6AA84F + أزرق داكن #1F4E79.
