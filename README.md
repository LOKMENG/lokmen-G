# منصة الرخصة المهنية للمعلمين

منصة عربية (RTL) للتدريب على اختبار **الرخصة المهنية للمعلمين**، مبنية بـ **PHP + MySQL** فقط
بدون أي إطار عمل أو مكتبات خارجية، تعمل على **XAMPP** وعلى **الاستضافة المشتركة والسيرفرات الخاصة**.

> ⚠️ **تنبيه قانوني:** التصنيفات داخل المنصة تنظيمية مرنة قابلة للتعديل من لوحة الإدارة،
> **وليست** تصنيفاً رسمياً معلناً من هيئة تقويم التعليم والتدريب (قياس) ولا تمثلها.
> لا تُرفع أي أسئلة إلا من ملفات يملك المالك حق استخدامها، والنظام يرفض تخمين أي إجابة غير واضحة.

## المزايا

**واجهة الطالب**
- صفحة تعريفية عامة: مسارات، مزايا، خطوات، أسعار، شهادات متدربين، أسئلة شائعة.
- أسئلة مجانية (بدون اشتراك) وتدريب حر مع تصحيح فوري وشرح.
- بنك أسئلة قابل للبحث والتصفية حسب المسار والمجال والصعوبة.
- اختبارات: محاكاة كاملة بمؤقّت، اختبار مخصص (مسار/مجالات/عدد/مدة)، تدريب، بنوك أسئلة القوالب.
- إحصاءات وتحليلات: نقاط القوة والضعف لكل مجال، تطوّر الدرجات، نسبة الجاهزية، توصيات.
- اشتراك 100 ريال (قابل للتعديل) بتفعيل يدوي بعد التحقق من إثبات التحويل، أو بوابات دفع سعودية.
- الدعم الفني، الإشعارات الداخلية، ربط اختياري بتلجرام.

**لوحة الإدارة**
- لوحة معلومات وإحصاءات، إدارة الطلاب والمشرفين، الاشتراكات والمدفوعات (اعتماد/رفض/تمديد/إلغاء).
- بنك الأسئلة: إضافة/تعديل/حذف جماعي، تنشيط، وسم «يحتاج مراجعة»، رفع بلاغات الأسئلة.
- **استيراد أسئلة**: من PDF (استخراج نص مدمج) أو TXT/CSV/JSON أو نص ملصوق → جدول مراجعة →
  إدخال بعد الاعتماد فقط، مع كشف التكرار ووسم ما ينقصه الجواب (بدون تخمين).
- إدارة المسارات والمجالات والمصادر (مع حقل إقرار حق الاستخدام)، قوالب الاختبارات،
  شهادات المتدربين، الإعدادات العامة والاشتراك، سجل التدقيق، وربط تلجرام.

## التشغيل السريع محلياً (XAMPP)

1. حمّل وثبّت [XAMPP](https://www.apachefriends.org/) (PHP 8.1+).
2. انسخ مجلد المشروع إلى `C:\xampp\htdocs\professional-license`
   (أو `htdocs/license`).
3. شغّل من لوحة XAMPP خدمتي **Apache** و **MySQL**.
4. افتح المتصفح على:

   ```
   http://localhost/professional-license/install.php
   ```

5. أكمل الخطوات: فحص المتطلبات → بيانات قاعدة البيانات (`root` وكلمة مرور فارغة على XAMPP الافتراضي)
   → بيانات الموقع وحساب المدير → تنفيذ التثبيت.
6. سجّل الدخول: `http://localhost/professional-license/auth/login.php`

**بديل يدوي:** استورد `database.sql` من phpMyAdmin، انسخ `.env.example` إلى `.env` وعدّل قيمه،
ثم أنشئ حساب المدير:

```bash
php tools/install-cli.php --db-host=localhost --db-name=professional_license \
  --db-user=root --db-pass='' --url=http://localhost/professional-license \
  --admin-name="مدير المنصة" --admin-email=admin@example.com --admin-phone=0550000000 \
  --admin-pass='Admin@12345' --create-db --yes
```

## إدخال بنك أسئلة جاهز (ملف SQL قديم)

لديك ملف فيه آلاف الأسئلة بصيغة `INSERT INTO questions (id, category, source, stem, …)`؟
لا تنفّذه مباشرة (أعمدته لا تطابق المنصة، وأغلب أسئلته بلا إجابة). استخدم الأداة التي
تحوّله وتصلح نصه وتصنّفه وتضعه في منطقة المراجعة:

```bash
php tools/import-legacy-bank.php --file=./tamyee3at.sql --out=./import-out --batch="تجميعات الرخصة" --track=2
# ثم نفّذ 00 ثم 10 ثم 20 من مجلد import-out في phpMyAdmin، وراجع من لوحة التحكم
```

📄 **[docs/استيراد-بنك-أسئلة-قديم.md](docs/استيراد-بنك-أسئلة-قديم.md)**

القاعدة الذهبية: **لا تُخمَّن إجابة، ولا يُخمَّن أصل كلمة مشوّهة** — كل ما لا يُعرف يُوسم للمراجعة البشرية،
ولا يظهر أي سؤال ناقص في اختبارات الطلاب.

## النشر على سيرفر خاص أو استضافة

الدليل الكامل خطوة بخطوة (cPanel والنشر على VPS مع Nginx/Apache، HTTPS، Cron، الويبهوك، النسخ الاحتياطي، الأمان، وحل المشكلات):

📄 **[docs/التثبيت-على-سيرفر.md](docs/التثبيت-على-سيرفر.md)**

الخلاصة:

```bash
php tools/build-package.php     # ينشئ حزمة ZIP جاهزة للرفع في storage/build/
php tools/build-package.php --with-tests --out=/path/lokmen-license.zip  # نسخة كاملة قابلة للفحص على السيرفر
# ارفع الحزمة إلى السيرفر وفك الضغط، أنشئ قاعدة البيانات،
# ثم افتح https://your-domain.com/install.php
# أو من سطر الأوامر:
php tools/install-cli.php --db-name=... --db-user=... --db-pass=... \
    --url=https://example.com --admin-name=... --admin-email=... \
    --admin-phone=... --admin-pass=... --create-db --yes
# بعد النجاح: احذف install.php وأضف مهمة Cron:
php tools/cron.php
```

## الاشتراكات والدفع

- السعر الافتراضي **100 ريال سعودي** والمدة **365 يوماً** — قابلان للتعديل من: لوحة الإدارة → الإعدادات → الاشتراك.
- دورة الاشتراك: `pending` (بانتظار الدفع) → `approved/active` (بعد اعتماد الإدارة) → `expired`.
- طرق الدفع الجاهزة: تحويل بنكي، STC Pay، نقداً في المركز، تفعيل يدوي من الإدارة.
- بوابات سعودية قابلة للتفعيل بالمفاتيح: **Moyasar** (مدى/Apple Pay/فيزا) و **MyFatoorah**،
  مع نقطة استقبال إشعارات متحققة من المبلغ والتوقيع: `api/payments/callback.php`.
- الاشتراك يمنح الوصول لكل المسارات أو لمسارات محددة حسب الباقة (`track_ids` في الباقة).

## بوت تلجرام (اختياري للطالب)

- الربط **طوعي تماماً**: من صفحة «ربط تلجرام» في حساب الطالب يُنشأ رمز (مشفّر، صالح 30 دقيقة، يُستهلك مرة واحدة).
- يُخزَّن الرمز كبصمة SHA-256 في جدول `telegram_link_codes`، ولا يُعرض الرمز إلا مرة واحدة.
- أوامر البوت: `/start` `/link` `/status` `/today` `/practice` `/stats` `/subscribe` `/support` `/unlink` `/privacy` `/cancel`.
- الإشعارات: تفعيل الاشتراك، قرب انتهائه، انتهاؤه، ردود الدعم، إشعارات الإدارة، وإثباتات الدفع الواردة من البوت.
- التوكن يُقرأ من `.env` فقط (`TELEGRAM_BOT_TOKEN`) ولا يُخزَّن في قاعدة البيانات.

## استيراد بنك الأسئلة من PDF

1. من لوحة الإدارة → **استيراد الأسئلة**: ارفع ملف PDF (نصي)، أو TXT/CSV/JSON، أو الصق النص.
2. يحلّل النظام الملف إلى أسئلة واختيارات وأجوبة وشروح، ويضعها في **جدول مراجعة** — بدون أي إدخال فعلي.
3. يوسم النظام تلقائياً: صفاً ناقصاً، مكرراً (بصمة المحتوى)، أو **بلا إجابة واضحة** ⇒
   `correct_answer = NULL` و `needs_review = 1` — **ولا يخمّن أي إجابة أبداً**.
4. تراجع الصفوف وتعدّلها، ثم «اعتماد المحدد» أو «اعتماد كل الصالح».
5. الإدخال النهائي إلى بنك الأسئلة باختيار المسار والمجال والمصدر والصعوبة، ويُسجَّل تقرير بكل عملية.

صيغ الإدخال المدعومة (TXT):

```
س1: نص السؤال؟
أ) الاختيار الأول
ب) الاختيار الثاني
ج) الاختيار الثالث
د) الاختيار الرابع
الإجابة: ب
الشرح: سبب صحة الإجابة (اختياري)
```

وللـ CSV: `question,option_a,option_b,option_c,option_d,correct_answer,explanation`
وللـ JSON: `[{"question":"...","options":["أ","ب","ج","د"],"correct":"أ","explanation":"..."}]`

## التصميم والواجهة

واجهة المنصة تدعم **قالبين** يختار بينهما المدير من:
**لوحة التحكم ← الإعدادات ← إعدادات عامة ← قالب التصميم**:

| الهوية | الملف | الافتراضي |
|---|---|---|
| **نيون كاربون (Neon Carbon — أخضر نيون داكن)** | `assets/css/neon-carbon.css` + `assets/js/neon-carbon.js` | ✔ الافتراضي |
| النسخة الأولى (الأخضر) | `assets/css/app.css` | اختياري |
| سيلادون (كلايمورفيزم) | `assets/css/celadon.css` + `assets/js/celadon.js` | اختياري |

التبديل: **لوحة التحكم ← الإعدادات ← إعدادات عامة ← قالب التصميم**.
الهوية الافتراضيّة هي **نيون كاربون** (مستوحى من قالب Tooplate 2165 Neon Carbon)،
وهي مبنية بالكامل للعربية و RTL: خصائص منطقية فقط (لا `left/right`)،
وواجهة الاختبارات محفوظة (المؤقّت، الخيارات، الملاحِق، حالات الصحيح والخطأ).
كل الألوان والظلال معرّفة كمتغيرات `--cl-*` في أعلى الملف، فتغيير الهوية اللونية يحتاج بضعة أسطر فقط، والوضع الليلي مدمج.

- القوالب تربط الطبقة **بعد** `app.css`، وملف التفاعل **بعد** `app.js` — لا تغيّر الترتيب.
- مع تعطّل الجافاسكربت يبقى كل المحتوى ظاهراً (الظهور التدريجي مُقيَّد بالصنف `cl-js`).
- احترام `prefers-reduced-motion` وأحجام الشاشات من 390px.
- **الاستخدام المجاني للقالب مشروط ببقاء روابط النسبة في التذييل** (TemplateMo / Tooplate) — لا تحذفها.

للتفاصيل الكاملة (الرموز، المكوّنات الجاهزة، قواعد الإضافة، وفحص السلامة) راجع
[`docs/التصميم-والواجهة.md`](docs/التصميم-والواجهة.md).

فحص سريع بعد أي تعديل على الواجهة:

```bash
php tools/dev/check-design.php   # يتحقق من سلامة الطبقة وربطها بكل القوالب
php tests/run.php                # يشمل اختبارات طبقة التصميم
```

## الأمان

التفاصيل الكاملة وتعليمات التحقق في [`docs/الأمان-والحماية.md`](docs/الأمان-والحماية.md)،
وقواعد nginx في `docs/nginx-security.example.conf`. أهم ما هو مطبَّق:

- **سياسة كلمة مرور قوية**: ١٠ أحرف على الأقل + حرف ورقم + رفض كلمات المرور الشائعة
  والمشتقة من البريد/الاسم/الجوال والأنماط المتكررة، مع مؤشر قوة من ٠ إلى ١٠٠.
- **تحديد معدل يقاوم انقطاع قاعدة البيانات**: العدّ في قاعدة البيانات **وفي ملف**
  ويُؤخذ الأكبر — أي أن الحماية تفشل مغلقة ولا تُعطَّل إن تعطّلت قاعدة البيانات.
- **حماية الجلسة**: إنهاء عند الخمول (`SESSION_IDLE_MINUTES`) وعند تجاوز العمر الأقصى
  (`SESSION_MAX_MINUTES`)، وتجديد المعرّف عند الدخول، وبصمة متصفح اختيارية.
- **رؤوس HTTP**: CSP، `nosniff`، `SAMEORIGIN`، COOP، CORP، `Referrer-Policy`،
  `Permissions-Policy`، وHSTS على HTTPS — مع إخفاء توقيع `Server`.
- **تقرير حماية فوري**: من سطر الأوامر `php tools/security-audit.php --json`،
  أو من لوحة التحكم ← **فحص الحماية** (يعمل على الاستضافة المشتركة بلا SSH).
- **حصر لوحة `/admin` بعناوين IP** اختيارياً عبر `ADMIN_IP_ALLOWLIST`.
- **تحويل إجباري إلى HTTPS** اختيارياً عبر `FORCE_HTTPS`.
- كل استعلامات قاعدة البيانات عبر **Prepared Statements** (لا يوجد دمج لأي مدخل مستخدم في نص الاستعلام).
- حماية CSRF تلقائية لكل طلبات POST، وتُعفى نقاط الاستقبال الخارجية فقط (ويبهوك تلجرام وبوابات الدفع).
- كلمات المرور: **Argon2id** إن توفر وإلا bcrypt بكلفة 12.
- ملف `.env` و`config/` و`src/` و`views/` و`includes/` و`storage/` و`tests/` و`tools/` و`docs/` محجوبة عن الوصول من المتصفح.
- رفع الملفات: فلترة الامتدادات ورفض ملفات التنفيذ (`php/phtml/phar`...)، ومجلد `uploads/` معطّل فيه تنفيذ PHP.
- مفتاح `APP_KEY` لتشفير مفاتيح بوابات الدفع بـ AES-256-GCM، ولا يُخزَّن أي مفتاح في قاعدة البيانات.
- سجل تدقيق `audit_logs` لكل عملية إدارية حساسة، وسجل رسائل تلجرام، وسجل أخطاء في `storage/logs/`.

## البنكان المرفقان (إدخالهما في قاعدة البيانات)

- **بنك الحاسب الآلي (٥١ سؤالاً)**: مُراجَع سؤالاً بسؤال (النص والخيارات والإجابة والشرح)
  ← **يُدرج مباشرة** في `questions` وجاهز للاستخدام.
- **البنك التربوي (١٠٨٧ سؤالاً)**: نصه مستخرج آلياً وإجاباته من المصدر (٦٣٥ «مقترحة»)
  ← **منطقة مراجعة** `import_staging`، ويُعتمد من لوحة التحكم سؤالاً بسؤال —
  لأن سياسة المنصة تمنع تخمين الإجابات أو إدخالها دون تأكيد.

```bash
mysql -u USER -p DBNAME < storage/import/attached-banks/01-sources.sql
mysql -u USER -p DBNAME < storage/import/attached-banks/02-computer-bank-51.sql
mysql -u USER -p DBNAME < storage/import/attached-banks/03-educational-bank-1087-review.sql
```

التفاصيل والأرقام الفعلية في [`docs/بنوك-الأسئلة-المرفقة.md`](docs/بنوك-الأسئلة-المرفقة.md)
و`storage/import/attached-banks/REPORT.md`.
